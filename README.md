# foundry-workshop-agent

A small, made-up repair-workshop app for Windows (WinForms on .NET 10), built from scratch so that
a local agent can later drive it through a generic, self-describing and locked-down HTTP endpoint.

This README is a stub. It is completed once the app, the endpoint and the screens exist.

## Build and test

```
dotnet build -c Release
dotnet test -c Release
```
